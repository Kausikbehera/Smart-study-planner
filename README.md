# 🌐 Smart Study Planner

This is a **Smart Study Planner web application** built using **HTML, CSS, and JavaScript**.  
It helps students organize their study schedule, manage tasks, and track academic progress efficiently.

---

## 🚀 Features
- Add, edit, and delete study tasks 📝  
- Visual timeline to track deadlines 📅  
- Progress tracking with total tasks, completed tasks, and completion rate 📊  
- Filter tasks by All, Pending, or Completed ✅  
- Instant notifications for task actions 🔔  
- Responsive design for desktop and mobile devices 📱

---

## 🛠️ Technologies Used
- HTML5  
- CSS3 (Flexbox & Grid)  
- JavaScript (ES6)  
- LocalStorage for saving tasks  
- Font Awesome for icons
